# Code of Conduct

## Our standard

Contributors and maintainers are expected to make participation respectful, technically honest, and safe.
Constructive disagreement is welcome; harassment, discrimination, threats, personal attacks, deliberate
misrepresentation, and disclosure of private information are not.

Good participation includes:

- Critiquing behavior, evidence, and code rather than people.
- Stating uncertainty and correcting mistakes openly.
- Respecting user authority, privacy, and security boundaries.
- Giving reviewers enough evidence to reproduce a claim.
- Avoiding pressure to merge changes that bypass documented safety or release checks.

## Scope

This standard applies in the repository, issue tracker, pull requests, discussions, release channels, and
other public spaces used to represent the project.

## Enforcement

Report conduct concerns through a private maintainer channel when one is available. Do not include sensitive
personal details in a public issue. Maintainers may edit or remove contributions, limit participation, or ban
participants whose behavior is unsafe or persistently disruptive. Enforcement decisions should be
proportionate, documented privately, and free from conflicts of interest.

Security vulnerabilities are handled separately under [SECURITY.md](SECURITY.md).
